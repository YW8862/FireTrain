# 身份切换功能完整说明

## 📋 功能概述

根据设计文档要求，FireTrain 系统实现了**管理员与普通用户之间的身份切换功能**。

### 核心特性

- ✅ **位置**: 顶部导航栏右上角，用户信息旁边
- ✅ **显示**: 当前角色标签（admin/root/user）
- ✅ **操作**: 下拉菜单中选择"切换到用户模式"或"切换回管理员"
- ✅ **权限**: 仅 `can_switch_role=true` 的管理员可以使用

### 2. 切换逻辑

```javascript
// 处理下拉菜单命令
const handleCommand = async (command) => {
  switch (command) {
    case 'switch':
      await handleSwitchRole()
      break
    case 'profile':
      router.push('/profile')
      break
    case 'logout':
      await handleLogout()
      break
  }
}

// 切换角色
const handleSwitchRole = async () => {
  try {
    const targetRole = isUserMode.value ? 'admin' : 'user'
    
    // 调用后端 API
    await switchRoleApi({ target_role: targetRole })
    
    // 更新本地用户信息
    await userStore.fetchUserInfo()
    
    if (isUserMode.value) {
      ElMessage.success('已切换为普通用户模式')
      router.push('/')  // 跳转到用户首页
    } else {
      ElMessage.success('已切换回管理员模式')
      router.push('/admin/dashboard')  // 跳转到管理后台
    }
  } catch (error) {
    ElMessage.error(error.message || '角色切换失败')
  }
}
```

## 🔧 后端实现

### 1. API 接口

**端点**: `POST /api/user/switch-role`

**请求参数**:
```json

  "target_role": "user"  // 或 "admin"
}
```

**响应数据**:
```json

  "role": "user",
  "original_role": "admin"

```

### 2. 业务逻辑

```python
async def switch_role(self, user_id: int, target_role: str) -> dict:
    """
    切换用户角色（临时）
    
    Args:
        user_id: 用户 ID
        target_role: 目标角色 ("user" 或 "admin")
        
    Returns:
        新的用户信息
        
    Raises:
        ValueError: 当用户不允许切换或角色不支持时
    """
    # 获取用户
    user = await self.user_repo.get_by_id(user_id)
    if not user:
        raise ValueError("用户不存在")
    
    # 验证是否允许切换
    if not user.can_switch_role:
        raise ValueError("该用户不允许切换角色")
    
    # 仅允许在 user 和 admin 之间切换
    if target_role not in ["user", "admin"]:
        raise ValueError("不支持的角色切换")
    
    # 保存原始角色
    if target_role == "user":
        # 切换到用户模式
        user.original_role = user.role
        user.role = "user"
    else:
        # 恢复管理员角色
        user.role = user.original_role or "admin"
        user.original_role = None
    
    # 更新数据库
    await self.user_repo.update(user, {})
    
    return {
        "role": user.role,
        "original_role": user.original_role,
        "message": f"已切换为{'普通用户' if target_role == 'user' else '管理员'}模式"
    }
```

## 🔐 权限控制

### 1. 谁能切换？

- ✅ **管理员** (`role="admin"` AND `can_switch_role=true`)
- ❌ **普通用户** (`role="user"`)
- ❌ **Root 用户** (建议不切换，保持最高权限)

### 2. 切换限制

```python
# 验证逻辑
if not user.can_switch_role:
    raise ValueError("该用户不允许切换角色")

if target_role not in ["user", "admin"]:
    raise ValueError("不支持的角色切换")
```

### 3. 路由守卫

```javascript
router.beforeEach((to, _from) => {
  // 检查角色权限
  if (to.meta.requiresRole && token) {
    const payload = JSON.parse(atob(token.split('.')[1]))
    const userRole = payload.role || 'user'
    
    if (!to.meta.requiresRole.includes(userRole)) {
      return '/'  // 权限不足，重定向到首页
    }
  }
})
```

## ⚠️ 注意事项

### 1. Token 更新

切换角色后，JWT Token 中的 `role` 字段会更新，但浏览器需要刷新才能生效。

**解决方案**:
```javascript
// 切换后重新获取用户信息
await userStore.fetchUserInfo()

// 强制刷新页面（可选）
window.location.reload()
```

### 2. 会话保持

切换角色不会使 Token 失效，只是更新了角色信息。

### 3. 权限缓存

如果前端有权限缓存，切换后需要清除：
```javascript
// 清除权限缓存
localStorage.removeItem('permissions')
```

### 4. 安全考虑

- ✅ 只有 `can_switch_role=true` 的用户才能切换
- ✅ 不能切换到 `root` 角色
- ✅ 每次切换都会记录到数据库
- ✅ 支持审计日志追踪
