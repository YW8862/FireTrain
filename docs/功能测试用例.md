# FireTrain 功能测试用例

> 核心功能验收用例，挑选 10 个关键场景，覆盖主链路与权限/异常分支。
>
> 文档版本：v1.0
> 最后更新：2026-06-09

## 1. 测试模块

| 序号 | 测试模块 | 关键能力 |
|------|----------|----------|
| M1 | 用户与认证 | 注册、登录、JWT 鉴权、退出、身份切换 |
| M2 | 训练主流程 | 开始训练、视频上传、预检测、AI 评分 |
| M3 | 个人统计 | 统计总览、趋势、步骤分析 |
| M4 | 后台 - 用户与管理员 | 用户/管理员 CRUD、密码重置 |
| M5 | 后台 - 训练与日志 | 训练查询删除、仪表盘、操作日志 |
| M6 | 后台 - 视频检测 | 管理员上传视频、状态查询、取消 |

## 2. 核心功能测试表

| 序号 | 测试模块 | 测试场景 | 预期结果 |
|------|----------|----------|----------|
| T01 | M1 用户与认证 | 用户注册：提交合法 username/email/password | 返回 200，提示「注册成功」，DB 新增用户 |
| T02 | M1 用户与认证 | 用户登录：form 提交 username + password | 返回 JWT token 与 user_info（role=student） |
| T03 | M1 用户与认证 | 权限校验：不带 token 访问受保护接口 | 返回 401，提示 Token 无效或缺失 |
| T04 | M2 训练主流程 | 训练完整链路：start → 上传视频 → 预检测 → 完成评分 | 全程返回 200，最终返回 total_score、step_scores、feedback、performance_level |
| T05 | M2 训练主流程 | 预检测失败：上传损坏或非训练视频 | 返回 is_valid=false，reason 描述失败原因 |
| T06 | M3 个人统计 | 统计总览：已完成多次训练后查询 | 返回 personal_stats、recent_trend、step_analysis 三段数据 |
| T07 | M4 后台用户管理 | 管理员重置用户密码 | 返回 200，生成临时密码并提示首次登录后修改 |
| T08 | M5 后台训练与日志 | 仪表盘统计：管理员查询整体数据 | 返回用户统计、训练统计、视频状态分布及时间戳 |
| T09 | M6 后台视频检测 | 管理员代用户上传视频并轮询状态 | 初始 status=processing 含 progress，多次轮询最终 status=done 并返回 total_score |
| T10 | M6 后台视频检测 | 权限边界：student 调 `/api/admin/video/*` | 返回 403，提示权限不足 |

## 3. 备注

- 上述用例为冒烟/核心回归用例，QA 可在此基础上扩展边界用例（参数异常、并发、跨用户访问等）。
- AI 评分（T04/T09）建议抽样不同光照/动作的视频，验证规则引擎与 LLM 评分的可解释性。
- 权限矩阵：student 仅可访问 M1/M2/M3；admin 可访问 M4 部分（不可管理 admin/root）、M5/M6 全部；root 拥有全部权限。
